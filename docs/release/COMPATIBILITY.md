# Preview compatibility status

| Area | Status | Blocking input |
|---|---|---|
| Minecraft protocol | partial | The production entry delegates Java protocol, Login → Configuration → Play and world networking to the authorized Pumpkin runtime. Mythicraft capability/payload hooks are linked into Pumpkin; real-client smoke evidence remains pending. |
| Anvil `DataVersion` | partial | Startup preflight reads an existing `level.dat` through Pumpkin and reports version/spawn data; the native bounded map diagnostic also summarizes region/区块 counts, versions, coordinate bounds and corrupt-region issues. The known Pumpkin range is `4435..=4903`; real licensed map evidence remains pending. |
| MythicMobs semantics | partial runtime integration | Pumpkin's native `MythicraftCore` scans supported MythicMobs YAML directories and imports supported definitions into the RPG IR. Skill/mechanic execution and full 5.13.0 coverage remain pending. |
| Vault economy semantics | partial native integration | `MythicraftCore` loads the supported Vault/VaultUnlocked configuration subset, instantiates the native economy, applies RPG rewards through the persistence transaction path, and restores player balances. Full VaultUnlocked API/plugin behavior remains pending. |
| LuckPerms semantics | partial native integration | `MythicraftCore` loads the supported LuckPerms configuration subset and evaluates native node/group/context rules. Full LuckPerms storage formats, inheritance edge cases and runtime synchronization remain pending. |
| Client capability protocol | partial runtime integration | Pumpkin forwards the `mythicraft:main` payload to native MythicraftCore, which negotiates capabilities and receives validated UI actions bound to the player's active page/session state. Real client/mod smoke evidence remains pending. |
| ArcartX UI configuration | partial native integration | `plugins/ArcartX/ui` and compatible aliases are scanned by the Pumpkin core; UI/tooltip YAML/JSON is preserved as a native Mythicraft UI model, HUD pages auto-open, and `/mythicraft ui <page>` opens other pages. ArcartX scripts, resource download/CRC, dedicated `arcartx:main` packets, and full non-UI config folders remain pending. |
| End-to-end server loop | partial | `mythicraft-server` owns the real Pumpkin loop, and RPG/compat/economy/permission/client payload state is directly linked into Pumpkin rather than a separate adapter plugin. Player persistence and native skill/loot/effect execution are wired into the tick/join/leave path; real map/client evidence remains pending. GitHub build/test evidence is required from a successful run of `.github/workflows/ci.yml`; this document does not claim that an unobserved run passed. Local Pumpkin build/check/test remains intentionally prohibited. |
